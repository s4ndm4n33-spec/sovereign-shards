# Projects Workspace

This folder contains project-level modules that are separated from the Sovereign Shards core agent.

- `cloud/` — J Cloud web landing pages and deployment assets.
- `github_agent/` — GitHub Models API integration and GitHub Actions runner.
- `jgpu/` — JGPU tensor runtime experiments and runtime implementation.
- `ide/` — Visual Studio Code/IDE integration components.
- `architect/` — architecture research, planning, and scaffolding.
- `fastapi_app/` — FastAPI demo application.
- `integrations/` — external integration metadata such as Slack.
